# Student Data Organizer

A simple, menu-driven Python application designed to manage student records. This project demonstrates Python fundamentals, including lists, dictionaries, loops, conditional statements, and basic CRUD operations.

## ✨ Features

### 1. Add Student
- Enter a unique student ID.
- Add the student's name, age, date of birth, grade, and subjects.
- Check for duplicate student IDs.

### 2. Display All Students
- Display all registered students.
- View student IDs, names, ages, grades, subjects, and dates of birth.

### 3. Update Student Information
- Search for a student using their ID.
- Update the student's age and subjects.

### 4. Delete Student
- Find a student by ID.
- Remove the selected student's record.

### 5. Display Subjects Offered
- Display a collection of available subjects, including Math, Science, English, Chemistry, Physics, Python, C Programming, and Gujarati.

### 6. Exit
- Exit the application using the menu.

## 🛠️ Technologies Used

- Python 3
- Lists and Dictionaries
- `while` and `for` loops
- Conditional statements
- User input and output
- Basic data management

## 🚀 How to Run the Project

1. Install Python 3 on your computer.
2. Download or clone the project repository.
3. Open the project folder in VS Code or another Python editor.
4. Open a terminal and run:

   ```bash
   python 01_Colleciton_Manipulator.py
   ```

   Replace the filename if your Python file has a different name.

5. Follow the on-screen menu to manage student records.
